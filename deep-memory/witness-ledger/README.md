# Witness ledger — source leaves

**Purpose:** Working source for Malcolm Sol Moonstar’s journal / session-touched recaps.  
**Site display:**
- Room + closed cover door: `deep-memory/witness.html`
- Open book (frame + pages): `deep-memory/witness-open.html`  
**Not:** a campaign chamber recap shelf (FoF sessions stay under `forge-of-fury/sessions/`).

## How to use after a session

1. Add a new markdown leaf here, numbered in order:
   - `02-….md`, `03-….md`, …
2. Title the file for the leaf (date or short name is fine).
3. Tell Atrok (or paste the leaf) so it can be turned into a **virtual page** in `witness.html`.

While Sol is an active character, this folder keeps growing. Each new leaf can become a turn of the tome.
